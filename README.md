# Hotel Booking System

### Summary
I made this project as a final project for a former course Advanced Computer Science. We were allowed to choose what we would like to develop, and I chose to make a hotel booking system. This project allows a user to book a room at a (make believe) hotel. The user is asked for their name, phone number, age, and how long they'd like to stay. I use multiple files, along with structs and arrays to hold the information from the files, to act as a rudimentary database. After getting the user's information, I store the data into updated files.

### Reflection
When I originally built this project, I did not know about databases such as SQL. The program utilizes a rudimentary database made up of multiple text files, structs, and arrays to organize the information. I plan to revisit the project, and implement a proper database. This would vastly improve the project, simplifying much of the logic and operations.
